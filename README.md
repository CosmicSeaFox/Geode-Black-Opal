## 🛠 Installation

1. Download or clone this repository.
2. Place the theme folder inside:

```text
YourVault/.obsidian/themes/
```

3. Open Obsidian.
4. Navigate to **Settings → Appearance → Themes**.
5. Select **Geode**.
6. Install and enable the **Style Settings** community plugin to unlock customization.
