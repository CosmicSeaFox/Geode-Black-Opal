# Installation

1. Download this repository.

2. Copy:

```
Geode-Black-Opal
```

into:

```
YourVault/.obsidian/themes/
```

3. Open Obsidian:

```
Settings → Appearance → Themes
```

4. Select:

```
Geode Black Opal
```
